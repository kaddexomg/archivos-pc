EXTRACTORES JJ PAPER PARA LA OTRA PC (Windows 7 con MixNet)
================================================================

ARCHIVOS A COPIAR AL ESCRITORIO DE LA OTRA PC:
  - extraer-clientes-mixnet.cjs
  - extraer-clientes-mixnet.bat
  - extraer-inventario-mixnet.cjs
  - extraer-inventario-mixnet.bat


EXTRACTOR 1: CLIENTES  (extraer-clientes-mixnet.bat)
-----------------------------------------------------
Opciones del menú:
  [1] EXTRAER  →  Flujo completo. Genera CSV de clientes con correo.
                  Siempre genera el archivo (apenas lee MXCTACLI).
                  Busca correos hasta 70% de cobertura o 10 min.
  [2] EXPLORAR →  Ver qué tablas DBF hay en la PC (con emails).
  [3] DIAGNOSTICAR →  Ver emails en una carpeta específica.

  Salida: clientes_mixnet_*.csv (escritorio)

  Otros archivos generados:
    clientes_sin_correo_*.csv  → los que faltan (captura manual)
    resumen_mixnet_*.csv       → estadísticas de cobertura


EXTRACTOR 2: INVENTARIO  (extraer-inventario-mixnet.bat)
---------------------------------------------------------
Auto-detecta tablas de artículos, precios, stock, familias y
proveedores por nombre de campo (no depende de nombres fijos).

Opciones del menú:
  [1] EXTRAER  →  Flujo completo. Busca tablas de inventario
                  y genera CSV con código, descripción, precio,
                  stock, familia, proveedor. Objetivo 85% precio.
  [2] EXPLORAR →  Ver qué tablas de inventario existen.
  [3] DIAGNOSTICAR →  Ver tablas de inventario en una carpeta.

  Salida: inventario_mixnet_*.csv (escritorio)

  Otros archivos generados:
    inventario_sin_precio_*.csv → artículos sin precio
    resumen_inventario_*.csv    → cobertura de precio/stock
    exploracion_inventario_*.csv→ todas las tablas encontradas


COMO FUNCIONA EL AUTO-DETECT:
  El extractor de inventario detecta automáticamente:
  - Tablas de ARTICULOS: tiene código + descripción + precio
  - Tablas de PRECIOS: tiene código + precio (sin descripción)
  - Tablas de STOCK: tiene código + existencia/saldo
  - Tablas de FAMILIAS: tiene código + familia/categoría
  - Tablas de PROVEEDORES: tiene código + proveedor/suplidor

  Detecta por nombres de campo (cod*, descri*, prec*, exist*,
  fam*, prove*, etc.). No importa cómo se llame el archivo .DBF


ESTRUCTURA DE ARCHIVOS EN EL ESCRITORIO:
  extraer-clientes-mixnet.bat     ← doble clic
  extraer-clientes-mixnet.cjs     ← código (no tocar)
  extraer-inventario-mixnet.bat   ← doble clic
  extraer-inventario-mixnet.cjs   ← código (no tocar)


SI NO FUNCIONA:
  - Ejecuta [2] EXPLORAR primero (en cualquiera de los extractores)
  - Revisa que M:/ P:/ Z:/ aparezcan como "OK"
  - Si no aparecen, verifica la red y las unidades montadas
  - Los reportes .csv te dicen exactamente qué tablas y campos hay


V3 DEL EXTRACTOR DE CLIENTES:
  - El CSV se genera desde el PRINCIPIO (no al final)
  - Busca correos por: código, RIF, teléfono, razón social
  - Cruce por código normalizado (003-03 == 3-3)
  - Va mostrando cobertura % en cada ronda

V1 DEL EXTRACTOR DE INVENTARIO:
  - Auto-detecta tablas por campos (no depende de nombres)
  - Prioriza carpetas tipo MixNet (comp01, RESPAMIX, etc.)
  - Es rápido: solo parsea tablas con campos de inventario
  - Presupuesto de tiempo configurable (default 10 min)
